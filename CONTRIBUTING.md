# Contributing to fates-edge-apps

This repo holds the web client, terminal client, and supporting utilities/voice tools.

Start at the [developer portal](https://dev.fates-edge.com) — the [architecture overview](https://dev.fates-edge.com/architecture) explains how this repo's clients talk to the transport layer and AI GM in `fates-edge-ai-gm-bot`, and [Ways to Contribute](https://dev.fates-edge.com/contribute) links straight into specific areas (web client polish, the terminal client, mobile/Slack/VTT surfaces, voice stack adapters).

UI work should follow the shared design tokens documented at [dev.fates-edge.com/design-tokens](https://dev.fates-edge.com/design-tokens) — the web client's `app.css` is the source of truth those tokens are derived from.

## Ground rules

- Open an issue before a large PR, or raise it in [Discussions](https://github.com/Chronophage-net/fates-edge-dev/discussions) first.
- Small, focused PRs over big ones where possible.
- Be kind — see the Code of Conduct on the [dev portal repo](https://github.com/Chronophage-net/fates-edge-dev/blob/main/CODE_OF_CONDUCT.md).
- **No AI-generated art.** UI icons and other visual assets contributed here must be human-made — traditional or digital, your call, but not output from an image-generation model. See the [No AI Art Policy](https://dev.fates-edge.com/no-ai-art) for the full reasoning and what this covers.
