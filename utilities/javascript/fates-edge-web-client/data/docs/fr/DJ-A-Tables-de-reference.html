Menu de dépense des Points d'Histoire (PH)

  • 1 PH : Pression mineure — bruit, indice, +1 segment sur un minuteur pertinent.
  • 2 PH : Revers modéré — alarme déclenchée, perte de couverture ou d'avantage, ennemi mineur apparaît.
  • 3 PH : Problème sérieux — des renforts arrivent, un équipement clé se brise temporairement, un front de campagne avance.
  • 4+ PH : Tournant majeur — un piège se déclenche, l'autorité arrive, la scène bascule radicalement.

Description des Positions

  • Dominant : Agissez selon vos conditions. Les conséquences sont gérables.
  • Maîtrisé : Risque et récompense normaux. L'échec a un vrai coût.
  • Désespéré : Les chances sont contre vous. L'échec pourrait être catastrophique.

Guide rapide de l'économie de Faveurs

  • Plafond : 5 Faveurs maximum.
  • Report : À la fin de chaque scène, réduisez les Faveurs détenues à 2 maximum.
  • Conversion : 2 Faveurs → 1 XP, une fois par séance pendant le temps mort (max 2 XP par séance via conversion).
  • Dépense : Relancer un dé, activer un atout, améliorer la Position, ou alimenter certains Rites.

Contraintes mécaniques

  • Maximum d'Assistance : +3 dés au total par jet (Coordination Exceptionnelle permet +4 depuis un seul suivant).
  • Maximum de Faveurs : 5 au total ; conversion 2→1 XP une fois par séance (max 2 XP via conversion).
  • Action indépendante d'un suivant : Une fois par scène (pour tout le groupe).

Actions de mouvement

  • Se déplacer : Changer d'une bande de portée (Proche ↔ Alentours ou Alentours ↔ Lointain).
  • Sprint : Changer de deux bandes en utilisant toute votre action.
  • Se dégager : Test pour quitter la portée Proche d'un ennemi sans provoquer d'attaque d'opportunité.
  • Charge / Escarmouche : Actions de tour complet qui déplacent de deux bandes et attaquent, coûtant 1 Fatigue.

Entretien (condensé)

Fréquence : Une fois par période de temps mort.

  • Efficace (plus d'XP, moins de temps) : XP d'entretien = max(1, XP d'acquisition ÷ 3).
  • Intensif (1 XP, action dédiée) : Une action de temps mort complète.
  • Défaut de paiement : La Loyauté du suivant se dégrade d'un cran : Fidèle → Tendue → Rompue ; l'Atout devient Négligé (ou Compromis s'il était déjà Négligé).
