    • Core resolution mechanics (dice pools, Position, DV, Outcome Matrix)
    • Boon and Story Beat economies
    • Fatigue, Harm, and Armor Conversion systems
    • Attribute and Skill descriptions
    • Basic combat and action economy rules
    • Universal magic mechanics (TAGS, DV calculation, Backlash)
    • NPC templates and encounter guidelines
    • Equipment and gear tables
    • Character creation framework

    • Artwork, maps, and graphical elements
    • Faction descriptions and campaign-specific content
    • Original prose, framing devices, and narrative text
