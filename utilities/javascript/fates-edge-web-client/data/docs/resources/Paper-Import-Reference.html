Fate's Edge — Paper Import Reference

Settings → Data Management → Import from Paper. Paste transcribed text, preview every value, then import once. Labels stay in English; names and text may use any language. This imports text, not photographs.

Section headerFields
=== Character ===Name required. Optional: ID, Body, Wits, Spirit, Presence, XP, Skills, Fatigue, Harm, Boons, Notes.
=== Timer ===Name, Segments required. Optional: Current (default 0). Creates a new timer; omit ID.
=== Journal ===Title, Content required. Optional: Tags. Creates a new wiki entry; omit ID.

Supported values

Attributes: 1–5. Skills: 0–5. Harm: 0–3. Fatigue and Boons: 0–100 (import limits, not rules caps). XP: 0–100000. Clock Segments: 4, 6, 8 or 10. Current: 0 through Segments. Values are totals, not amounts to add; the importer does not spend XP or validate a character build.

Skills: Melee, Ranged, Athletics, Stealth, Endurance, Craft, Sway, Deception, Performance, Insight, Lore, Arcana. Separate skill ratings with commas: Melee=2, Lore=1. Tags also use commas. Skills, Tags, Notes and Content may continue on following lines; use no colon on continuation lines. Lines starting with # are comments.

Updates and transcription

Without ID, a character block creates a new character with usual defaults. To update one, copy its exact id from an exported backup into ID:; keep Name and include only changed fields. Other fields and unlisted skills stay unchanged. Names alone never select an existing character. Duplicate or unknown IDs stop the import.

Numeric O → 0 and I/l/| → 1 repairs are shown for review. Invalid numbers, unknown labels and repeated fields must be fixed. Check all OCR text against the paper. Connect to the intended campaign before importing; delivery uses sync and its offline queue. Do not re-import to retry a pending delivery.
