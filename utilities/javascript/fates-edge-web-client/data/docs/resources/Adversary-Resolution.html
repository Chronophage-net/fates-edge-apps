Setup

A Setup uses an action and only calls for a roll when its outcome is uncertain and consequential. For one following action, use the strongest applicable Setup benefit; repeated Setups do not accumulate numerical bonuses. A genuinely different approach may change the fiction. Assist remains the separate Boon-funded +1 die option, subject to the dice-pool cap.
