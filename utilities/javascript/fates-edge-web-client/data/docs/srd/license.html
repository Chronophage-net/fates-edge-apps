System Reference Document (SRD) Reference

  • What is the SRD? The open-license portion of this work (CC BY-NC-SA 4.0), intended for third-party creators. All SRD content is marked with [SRD] tags in this book.
  • Verified SRD Content Includes:
    • Core resolution mechanics (dice pools, Position, DV, Outcome Matrix)
    • Boon and Story Beat economies
    • Fatigue, Harm, and Armor Conversion systems
    • Attribute and Skill descriptions
    • Basic combat and action economy rules
    • Universal magic mechanics (TAGS, DV calculation, Backlash)
    • NPC templates and encounter guidelines
    • Equipment and gear tables
    • Character creation framework
  • Extended Content (Not SRD - Proprietary):
    • Setting lore (Acasia factions, The Curse, regional details)
    • Original characters, NPCs, and named figures
    • Adventure modules and scenario hooks
    • Patron descriptions, Rites, and exclusive mechanical content
    • Proprietary magic systems (Runekeeper, Invoker, Cantor, Summoner-specific)
    • Artwork, maps, and graphical elements
    • Faction descriptions and campaign-specific content
    • Original prose, framing devices, and narrative text
    • Note: Optional systems like Deck of Consequences, Crown Spread, and Travel Framework are proprietary content.
