Reference and Navigation

How to Use This Chapter

This chapter provides a structured index and navigation guide to the regions, mechanics, and cartomancy tools of the Amaranthine Core.

For the cartomancy generator procedure, see §The Cartomancer’s Compass. For travel procedures and the Wilds hexcrawl, see §2.1.
