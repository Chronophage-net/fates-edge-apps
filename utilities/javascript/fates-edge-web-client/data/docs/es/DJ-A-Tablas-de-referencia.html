Punto narrativo (SB)

  • 1 SB: Presión menor — ruido, traza, + 1 segmento sobre un temporizador relevante.
  • 2 SB: Retroceso moderado — alarma levantada, perder tapa o ventaja, menor enemigo aparece.
  • 3 SB: Problemas serios — los refuerzos llegan, los engranajes clave rompen temporalmente, marcan un frente de campaña.
  • 4 + SB: Mayor giro — primaveras trampa, la autoridad llega, cambios de escena dramáticamente.

Descripción de posición

  • Dominante: Actúa en sus términos. Las consecuencias son manejables.
  • Controlada: Riesgo normal y recompensa. El fracaso tiene un costo real.
  • DesesperadaLas probabilidades se apilaron contra ti. El fracaso podría ser catastrófico.

Bono Economía Guía rápida

  • Tener tapa: 5 Bonos máximo.
  • Conservación: Al final de cada escena, reduzca Bonos a un máximo de 2.
  • Conversión: 2 Bonos → 1 XP, una vez por sesión durante el tiempo de inactividad (max 2 XP por sesión mediante conversión).
  • Gasto: Re-rollar una muerte, activar un activo, mejorar la Posición o potenciar ciertos Rites.

Constraints mecánicos

  • Ayuda Max: +3 dados totales por tirada (Coordinación Excepcional permite + 4 de un seguidor).
  • Bono Max: 5 total; 2→ 1 XP conversión una vez por sesión (max 2 XP via conversion).
  • Acción independiente del seguidor: Una vez por escena (partidista)

Movimientos Acciónes

  • Mover: Shift una banda de gama (Close ↔ Cerca o Cerca ↔ Far).
  • Esprintar: Shift dos bandas como su acción completa.
  • Retirarse: Prueba para dejar el rango cercano de un enemigo sin provocar un ataque de oportunidad.
  • Carga / Esquímica: Acciones de giro completo que mueven dos bandas y ataque, costando 1 Fatiga.

Mantenimiento (resumen)

Frecuencia: Una vez por período de inactividad.

  • Eficiente (más alto XP, menos tiempo): Upkeep XP = max(1, Adquisición XP ÷ 3).
  • Intensivo (1 XP, acción dedicada): Una acción de tiempo completo.
  • Falta de pago: La lealtad del seguidor empeora un paso: fiel → Strained → Roto; recurso se vuelve Desatendido (o Comprometido si ya no reflejado).
